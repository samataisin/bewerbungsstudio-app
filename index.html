Zuerst dein Paket laden: Tab „Einstellungen“ → „Paket laden“. Ohne Paket kennt die App weder deinen Lebenslauf noch deine Textbausteine.

    4. Senden

    „Mappe teilen“ öffnet das Teilen-Menü. Dort „Mail“ wählen: PDF und Text sind schon drin. Empfänger und Betreff vorher hier kopieren und in der Mail einfügen.

    Nach 14 Tagen ohne Antwort steht „Nachfassen fällig“. Dann eine kurze, freundliche Nachfrage schicken.

    Paket

    Das Paket baust du auf dem Laptop mit python bewerbung/src/prepare_web.py. Es enthält dein Profil, die Textbausteine, Lebenslauf und Zeugnis. Es wird nur auf diesem Gerät gespeichert und nie hochgeladen.

    Auf den Home-Bildschirm

    In Safari unten auf „Teilen“ tippen, dann „Zum Home-Bildschirm“. So startet die App wie eine normale App, funktioniert ohne Internet und iOS löscht deine Daten nicht automatisch.
